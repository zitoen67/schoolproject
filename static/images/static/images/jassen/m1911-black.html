Colt M1911 Pistol Black 3D Model

This Colt M1911 Pistol Black is made while keeping the perspective of the production. It is a low poly model and it can be sub divided. You can apply Subdivision Surface/TurboSmooth on it.I have used highly detailed textures and also kept it low on poly count, You can use it for production and in game. For textures, I have used Substance Painter. The model is made in Blender 3.3.18.0 and rendered in Cycle.

Included file formats:

Blender (Native)
3DS Max 2021.3ds
C4D R20.c4d
Lightwave.lwo
Modo.lxo
Rhino 6.3dm
Autodesk.FBX
MTL
OBJ


Note No 1: For Game, might you need to apply one Subdivision Surface to avoid little shading problem. There is no shading problem in Subdivision Surface.

Note No 2: Textures' size is 4096x4096. (resizeable)

Included Maps:

Normal Map
Base Color Map
Displacement Map
Roughness Map
Metallic Map

Note No 3: Rendering Studio is not included.
